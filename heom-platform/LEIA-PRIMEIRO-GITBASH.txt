HEOM 0.4.0 — APLICAÇÃO INTEGRADA

Abra o Git Bash na pasta heom-platform (onde está o package.json principal).

REQUISITOS:
- Node.js 22.x;
- npm 10 ou superior.

PRIMEIRA EXECUÇÃO:
1. Instale todas as dependências com uma única instalação:
   npm install
2. Inicie a aplicação integrada:
   npm run dev
3. Abra no navegador:
   http://localhost:5173

O comando npm run dev inicia um processo Node e uma única porta. Interface React/Vite e API Express são servidas pelo mesmo endereço. Não abra outro terminal para iniciar backend ou frontend. Não é necessário criar .env nem configurar PostgreSQL, Supabase, MQTT, JWT, e-mail ou senha.

Na primeira visita, selecione um perfil demonstrativo: Administrador, Gestor, Operador ou Consulta. O seletor do cabeçalho permite alternar o perfil durante o uso.

BUILD E TESTES:
   npm run typecheck
   npm test
   npm run build
   npm start

npm start executa o build já gerado na mesma porta 5173.

PUBLICAÇÃO VERCEL:
- Repositório: thiagosantos-byte/projetoheom
- Root Directory: heom-platform
- Install Command: npm install
- Build Command: npm run build
- Output Directory: apps/web/dist
- Nenhuma variável de ambiente é necessária para o modo de demonstração.

DADOS E LIMITES:
- Todos os registros são fictícios e aparecem como SIMULADO.
- Dados: localStorage; fotos: IndexedDB. Cada navegador mantém sua própria demonstração.
- O OCR automático não está disponível no modo web; use a revisão/transcrição manual.
- A comparação visual usa dHash; não é reconhecimento por IA.
- O QR por câmera depende de BarcodeDetector; também há entrada manual/scanner USB.
- A planta e o rastreamento são ilustrativos/simulados; não há gateways físicos.
- Os perfis não são autenticação nem proteção adequada para produção.

Para detalhes, consulte README.md e docs/.
